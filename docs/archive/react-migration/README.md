# Archived: React migration planning artifacts

These are historical planning and execution-evidence documents from the completed
incremental React component migration (Phases 1–7, completed 2026-09-07). They are kept for
reference, not current specs or open work — nothing in this directory describes the
architecture as it exists today.

- For the current architecture, read `CLAUDE.md`'s "Hard constraints" and "Repo layout"
  sections.
- For the phase-by-phase narrative of how that architecture was reached, read
  [`docs/react-migration-history.md`](../../react-migration-history.md).
- `react-migration-evidence.md` is the accumulated per-phase build/test/manual-verification
  evidence log; `react-phase-*-plan.md` are each phase's bounded implementation plan as
  written before that phase began.
