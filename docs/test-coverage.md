# Behaviour test coverage migration map

This is the immutable migration inventory for the behaviour matrix at commit
`786b67884cef8eed3c1690a756c92ba9fef29a04`. It records all **255** original table rows
before consolidation. Old rows are identified by section and ID; the two distinct
`Note editing / E42` rows are intentionally retained as two inventory entries and map to
the same consolidated editing scenario without becoming indistinguishable historically.

The original identifier collisions are: `S*` (Playback speed and Separation panel),
`N*` (Notes lane and Language), `T*` (Transport and Tempo grid), plus the duplicate
`Note editing / E42`. Canonical IDs identify the globally unique retained scenarios; repeated values below are
intentional merge targets. Every merged row points to that retained live scenario and may also
name exact automated evidence. No related helper test is counted unless it proves the contract.

Contract groups correspond to the product-contract sections: loading music; playback and
routing; transport, loops, and speed; local stem separation; notes, tempo, and visual
reference; editing and persistence; human-readable export; language and resilience; and
release integrity.
